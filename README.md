# СК «Сириус» — Высокотехнологичный сайт-каталог

Официальный веб-сайт компании **СК «Сириус»** (г. Красноярск) — производство и монтаж ограждений, перил и поручней из нержавеющей стали (AISI 201 / AISI 304), пандусов, аппарелей и специализированного оборудования для МГН по ГОСТ и СП.

## Особенности архитектуры
- **Single Page Application (SPA)**: мгновенное переключение между экранами без перезагрузки страницы (Главная, Полный каталог на 16 моделей, Интерактивный калькулятор, Контакты).
- **Интерактивный 3D-движок (Three.js)**: кинетическая кибер-навигационная модель созвездия «Сириус-α» и CAD-карданы с параллаксом и световыми импульсами.
- **Интерактивный калькулятор сметы**: расчет стоимости в реальном времени с учетом марки стали и опций монтажа.
- **Интеграция с Telegram**: мгновенная отправка заявок с формы прямо в рабочую группу инженеров и замерщиков.
- **Адаптивность**: оптимизирован для всех экранов от смартфонов до широкоформатных 4K мониторов.
